# 权限 / 资源申请模板（可直接改写后发给老师或信息中心）

> 用法：把 `【】` 里的内容替换成实际信息，删掉不需要的段落。三封分别对应：活动审批、服务器与域名、公众号授权。

---

## 模板 A：给学院团委 / 指导老师（活动上线审批）

```
【老师姓名】老师您好：

本次"【活动全称】"拟采用自建线上投票页面（非第三方表单），用于作品展示与投票统计。
现将方案要点报备如下，请审批：

一、用途与范围
  · 页面地址（拟）：https://【vote.xxx.edu.cn】
  · 展示内容：参赛作品图片 + 200 字以内创作阐述（由参赛者本人提供）
  · 投票规则：每人每天限投 1 票，投票后当日不可更改
  · 起止时间：【11 月 20 日 00:00】开启，【11 月 24 日 24:00】关闭，之后仅展示、不再接受投票
  · 成绩使用：仅统计票数，最终成绩按"70% 评审 + 30% 投票"折算，由工作人员在 Excel 中计算

二、数据与合规
  · 系统仅记录：投票时间、所投作品、投票人标识（微信 openid 或浏览器随机标识）、IP 与 User-Agent
  · 用途：仅用于防刷票与异常核查，不对外公开、不用于其他目的
  · 活动结束后【删除 / 归档】原始明细，仅保留汇总票数
  · 页面底部已注明主办/协办单位与"自建投票系统，未使用第三方表单"

三、需要配合的事项
  1. 公众号"【哲样青春】"管理员协助配置"网页授权域名"并提供 AppID/AppSecret（用于识别投票人，避免刷票）
  2. 服务器与域名资源（如由学院协调，见模板 B）
  3. 活动通知/推文中附上投票二维码与规则说明

四、风险说明
  · 微信内投票可做到"一个微信号每天一票"；电脑浏览器打开时退化为浏览器标识识别，严格度较低，
    建议推文引导"请在微信中打开"
  · 已做后台留痕，可对异常记录（同 IP 短时大量投票等）作废处理

请指示是否同意按上述方案执行。

【你的姓名】/【学院、年级】/【联系电话】
【日期】
```

## 模板 B：给学校信息化办公室 / 网络中心（服务器与域名）

```
【信息中心老师】您好：

【学院】将于【11 月 20 日—11 月 24 日】举办"【活动全称】"，需部署一个轻量投票页面
（Node.js + SQLite，单进程，内存占用约 60MB，仅内网访问数据库文件，不连外部数据库）。

现申请以下资源与权限，恳请支持：

一、服务器
  · 规格需求：2 核 2G / 20G 磁盘（Ubuntu 22.04 或 Debian 12）
  · 运行方式：Node.js 24（`node --experimental-sqlite server.js`），由 systemd 守护
  · 申请：SSH 账号 1 个（或容器），目录 /var/www/campus-vote 的读写权限
  · 端口：内网放行 8787（仅本机 Nginx 访问）；公网放行 443（80 用于跳转与证书续期）

二、域名与证书
  · 申请子域名：vote.【xxx.edu.cn】，A 记录指向上述服务器 IP
  · 需要：域名解析记录添加权限（或请代为添加）
  · HTTPS：使用学校统一证书；若没有，申请允许用 Let's Encrypt 自动签发与续期

三、备案
  · 若使用学校已备案域名，本项可略
  · 若需新增备案，请告知所需材料与流程（主体：武汉大学 / 【学院】）

四、时间
  · 期望【11 月 X 日】前完成部署与联调，以便活动前彩排

附：系统说明
  · 单页 H5 + Node 服务，无第三方依赖、无外部 CDN 依赖（如需可改为本地打包）
  · 数据存储：服务器本地 SQLite 单文件，每小时增量备份到 /var/backups
  · 安全：后台密码登录（8 小时会话、失败限速）、Cookie 签名防篡改、截止时间服务端强制校验

【你的姓名】/【学院、年级】/【联系电话】
【日期】
```

## 模板 C：给公众号管理员（网页授权 / openid）

```
【管理员】您好：

"【活动全称】"的投票页面需要接入公众号网页授权（snsapi_base，静默获取 openid），
用于实现"一个微信号每天限投一票"，防止刷票。需要您协助三件事：

一、配置网页授权域名
  公众号后台 → 设置与开发 → 公众号设置 → 功能设置 → 网页授权域名
  填写：vote.【xxx.edu.cn】
  （校验文件 MP_verify_xxxx.txt 我方已放到站点根目录，可直接访问）

二、提供参数
  · AppID：在 设置与开发 → 基本配置 中查看
  · AppSecret：同页"重置/生成"后复制（仅显示一次，请通过安全渠道发送）

三、IP 白名单（若已开启）
  · 服务器公网出口 IP：【x.x.x.x】，请加入白名单
  · 若不便维护，也可临时关闭 IP 白名单（活动期间）

说明：该授权不获取昵称头像等个人信息，仅获得 openid（对本公众号唯一的匿名标识），
用于投票去重；活动结束后不再使用。

【你的姓名】/【联系电话】/【日期】
```

## 小贴士

- 三封可以**合并成一封**发给指导老师，由老师转给信息中心和公众号管理员，效率更高。
- 提前问清楚："学校域名能不能开子域？备案主体是学校还是学院？"这决定备案要不要重走流程。
- 微信认证服务号年审约 300 元/年，如果"哲样青春"已认证，直接找管理员要 AppID/AppSecret 即可。
- 如果时间来不及（备案 7–20 天），先用 Render 免费版顶上，等活动结束再把数据导回（CSV 互通）。
